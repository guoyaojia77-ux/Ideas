# 快速上手

## 安装

从本仓库 Releases 下载 Windows x64 的 .exe 安装包。Source code 压缩包仅为展示资料。安装后从桌面或开始菜单打开「想法 Ideas」。

## 新建与收集

左侧新建可选择画布、文本、画板、场景设计或分镜表。页面按日期自动命名，可右键重命名、分类或置顶。空白画布双击创建文字；右键打开创建菜单；图片、视频、音频和支持的文档可拖入。

## 连接与组织

拖动便签边上的端口到另一张便签附近建立连线，右键或 Esc 取消。单击连线后 Delete 删除。合集用于叠放收纳，组合用于有边界的框架。画布 Ctrl + 滚轮缩放、右键拖动平移；Q + 滚轮旋转选中图层，Alt + 滚轮缩放图层。

## 参考与写作

将左侧页面拖到工作区，在右侧并排查看或编辑。彩色方块用于切换页面，× 收起侧栏，主区右上角面板图标恢复。侧栏的在主区打开会收起右侧。画布旁的文本可插入为大便签，保留原文档。

## 随手记

Ctrl + 空格每次新开一个独立空白窗口；也可点击左侧随手记。标题可留空，正文提示不属于内容。可以置顶、保存、打开历史记录或导入画布。关闭主窗口后，默认可驻留托盘；退出托盘后全局快捷键不再工作。

## 画板和分镜

画板提供图层排序、可视化笔刷库、颜色历史和调色盘。Ctrl + 滚轮缩放，右键或手形平移。将左侧画布或画板拖到分镜表画面格生成快照；修改来源后可手动刷新。画布中的分镜表按镜头数量自动向下延伸。

## 背景与数据

外观与画布可定制底色、线条、表情矩阵和 PNG 图案，实时预览后选择全局应用或只应用于当前线程。数据入口可插入表格、折线图、柱状图和树状图，选中后在右侧编辑。

## 保存与升级

设置中可查看数据和笔刷目录。备份时同时保存数据 JSON 与 Media 素材目录。升级安装同一路径通常保留数据，但建议先备份。不要把个人数据、密钥或缓存提交到 GitHub。
