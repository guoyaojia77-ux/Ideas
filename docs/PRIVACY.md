# 隐私与数据

笔记和素材保存在本机，数据位置可在设置中查看与迁移。新电脑通常使用 %APPDATA%\Ideas\Data；旧版已有配置会继续沿用原目录。请通过应用显示的路径为准，不要只备份安装目录。

AI 助手需自行配置兼容服务。默认发送明确附加的材料；开启允许查询工作空间后，模型可通过只读工具读取其他笔记。接口提供商接收所发送内容，其存储和隐私规则由该提供商决定。API 密钥使用系统加密机制存储，不包含在本仓库和官方发布包中。

网页缩窗预览会连接目标网站；语音输入调用 Windows 系统功能，可能使用微软的在线服务。下载安装包和阅读本仓库分别会连接 GitHub 及其资源服务。
