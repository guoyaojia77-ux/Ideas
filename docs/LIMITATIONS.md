# 当前已知边界

本产品仍处于 0.x 预览阶段。截图展示现有界面，不表示已完成所有设备、格式与输入法兼容性测试。

- Windows x64：当前唯一提供安装包的平台，未提供 macOS / Linux 构建。
- 独立画板橡皮为整笔擦除；无限画布涂鸦另有局部矢量擦除。
- 数位笔压感依赖设备上报，鼠标为固定压力。
- MyPaint .myb 仅转换基础半径、不透明度、硬度等参数，不运行完整 MyPaint 引擎；ABR 不支持。
- PSD 为位图图层，不是完整 Photoshop 原生工程；复杂混合或调整在其他软件中可能有差异。
- 场景设计为基础俯视摆位工具，不是三维建模或专业拍摄模拟器。
- 分镜画面引用为快照，修改来源后需要手动刷新；画布分镜引用会随镜头数量延长。
- Office 附件使用本机应用打开，不提供完整 Office 内嵌编辑。
- 图层插件 v1 为声明式字段卡片，不执行任意第三方代码。
- 数据图层最多 200 行数据和 20 列，图表最多显示 6 个系列；表格预览行数可配置。
- 没有云同步，也没有自动更新服务。请自行备份并从 Releases 获取更新。
- AI 需要自行配置接口、模型和密钥，服务费用及可用性由所选提供商决定。
- 安装包尚未进行商业代码签名。
