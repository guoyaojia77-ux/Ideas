# 常见问题

### 这是开源项目吗？

目前不是。这里公开展示资料、帮助和安装包，应用源码暂不公开。没有添加 MIT 或其他应用开源许可证。

### 下载哪一个文件？

请选择 Releases 中的 Ideas-Setup-0.13.1-x64.exe。Source code 压缩包只是这个展示仓库的自动归档。

### 是否需要账号？

本地笔记功能不需要云账号。AI 功能需要自己的服务配置。

### Ctrl + 空格没有反应？

先确认应用仍在运行或驻留托盘，快捷键可能被输入法或其他软件占用，可在设置中更改。多次触发会创建多个独立小窗。

### 数据保存在哪里？

请以设置里显示的数据目录为准。新电脑默认使用 Windows 应用数据目录，旧配置会延续。数据迁移前请备份，备份要包含 JSON 与 Media 素材。

### 图很长，导出失败怎么办？

长图存在尺寸上限；可改用 PDF、缩小范围或分批导出。导出大型 PSD 时也存在图层与像素上限。
