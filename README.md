## 这是「想法」

**想法 / Ideas** 是一款为 Windows 打造的桌面笔记软件，也是一张围绕「想法与图层」展开的无限画布。

它源于一个日常需求：记下一个点子应该足够方便，整理灵感也应该足够自由。文字、便签、图片、绘画和镜头构思，都可以拥有自己的位置，通过连线、组合与页面引用建立关系。

从 Ctrl + 空格唤出的随手记，到无限画布、文本编辑、独立画板、场景设计和分镜表，你可以把零散想法逐渐整理成可阅读、可绘制、可继续创作的内容。数据保存在本机，适合头脑风暴、写作、视觉构思与影视前期规划。

这里是 **公开展示与安装包发布仓库**，当前**不公开应用源码**。作者：**小郭奉孝**。

## 三个彼此相连的创作空间

### 无限画布：让想法自由生长

把便签、文字、图片与其他素材拖进来，自由移动、缩放、旋转和调整图层。用连线表达关系，用组合框架整理一个主题，用叠放合集收好零散材料。文本、画板和子工程可以作为创作的一部分呈现在画布里。

### 场景设计：先把空间关系摆出来

在独立页面中安排人物、摄像机、灯光、墙体和布景，帮助梳理人物站位、拍摄方向与场景布局。场景设计也可以作为画布里的子工程，从整体思路进入具体编辑。

### 分镜表：把构思排成镜头

为镜头整理预览图、文字描述与时长，将画布或画板的内容生成快照放入预览格。分镜表插入无限画布后，会随镜头数量自动延长，方便连续阅读。

## 下载与安装

1. 打开 [Releases](https://github.com/guoyaojia77-ux/Ideas/releases)。
2. 下载 **Ideas-Setup-0.13.1-x64.exe**，按安装向导选择目录。
3. 启动「想法 Ideas」，从左侧「新建」选择画布、文本、画板、场景设计或分镜表。

**当前提供 Windows x64 预览版。**其他平台暂未提供安装包。安装包尚未进行商业代码签名，Windows 可能显示未知发布者提示；请确认来源后自行决定是否安装。

GitHub 自动提供的 **Source code (zip / tar.gz)** 只包含本仓库的展示资料，**不是应用安装包，也不是应用源码**。

## 常用操作

| 操作 | 快捷方式 |
| --- | --- |
| 新开随手记 | Ctrl + 空格 |
| 画布缩放 | Ctrl + 滚轮 |
| 画布平移 | 右键拖动 |
| 创建文字 | 双击画布空白 |
| 多选 | 空白处左键拖框 |
| 旋转选中图层 | 按住 Q + 滚轮 |
| 缩放选中图层 | Alt + 滚轮 |
| 撤销 / 重做 | Ctrl + Z / Ctrl + Shift + Z |

快捷键可在设置中调整；全局快捷键可能与其他软件冲突。

## 数据在本机，AI 由你选择

不需要注册云账号即可使用本地笔记功能。新安装通常将数据存放在 Windows 用户的应用数据目录，可在设置中查看和迁移；升级前建议备份数据与素材。

「思索」需自行配置兼容 API 的接口、模型和密钥。发送消息时会发送附加材料；允许查询工作空间后，才可读取其他笔记。网页预览会访问目标网址，系统语音输入由 Windows 提供。
